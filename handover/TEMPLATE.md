# Handover outline

Write for someone who starts with no memory of the session and cannot see the transcript.
Keep it factual, name real paths and commands, and cut anything the next agent does not need.

## 1. Goal
What the user is trying to achieve, in two or three sentences. Include the user's own words where they matter.

## 2. Done
What is finished and verified. One line each, with the file path or command that proves it.

## 3. In flight
What is half done right now: which file, which function, what state it is in, what breaks if it is left as is.

## 4. Files touched
Path plus one line on what changed in it. Mark anything not yet saved or not yet tested.

## 5. Decisions and why
Choices already settled, each with its reason, so the next agent does not reopen them.
Include options the user rejected.

## 6. Next steps
An ordered list, smallest first. Say what "done" looks like for each one.

## 7. Open questions
Anything waiting on the user, and what is blocked until it is answered.

## 8. Environment notes
Commands to run, services to start, credentials or paths that are easy to get wrong.
